# Matrix Functions as Dynamics — visual experiments

A self-contained static GitHub Pages tutorial based on Nicholas J. Higham, *Functions of Matrices: Theory and Computation*, Chapters 10–12.

## Publish on GitHub Pages

1. Create a public repository, e.g. `matrix-functions-visual-experiments`.
2. Upload **all contents of this folder** to the repository root, keeping `assets/` and `matrix-functions-experiments.ipynb`.
3. Open **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/ (root)` and save.
4. The page URL will be `https://annazhou.github.io/matrix-functions-visual-experiments/` if that is the repository name.
5. The article works as static HTML with no build tools. MathJax and Google Fonts need an internet connection.

## Repository contents
- `index.html`: complete article, CSS, SVG-based interactive rotation and JavaScript
- `assets/*.png`: original notebook output figures
- `matrix-functions-experiments.ipynb`: executed computational notebook
